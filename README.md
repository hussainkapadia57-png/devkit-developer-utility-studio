# DevKit — Developer Utility Studio

**One Workspace. Essential Developer Tools.**

DevKit is a modern, privacy-focused developer utility studio that brings essential development tools together in one unified workspace.

Designed for developers, programmers and technical enthusiasts, DevKit aims to simplify everyday development tasks through a clean, intuitive and powerful interface.

Instead of switching between multiple websites for simple operations, developers can access their essential utilities from one application.

## ✨ Features

DevKit brings together a collection of browser-based developer utilities.

### Developer Utilities

| Tool | Description |
|---|---|
| JSON Formatter & Validator | Format, minify and validate JSON data. |
| Base64 Encoder / Decoder | Encode and decode Base64 text. |
| JWT Decoder | Decode JWT headers and payloads. |
| Regex Tester | Test regular expressions and inspect matches. |
| URL Encoder / Decoder | Encode and decode URL components. |
| Text Diff Checker | Compare text and identify differences. |
| Hash Generator | Generate SHA-1, SHA-256, SHA-384 and SHA-512 hashes. |
| UUID Generator | Generate universally unique identifiers. |
| Timestamp Converter | Convert Unix timestamps into readable dates. |
| HTML / CSS / JS Minifier | Minify web development code. |
| Case Converter | Convert text into different naming conventions. |
| Color Converter | Convert HEX, RGB and HSL colour formats. |

## 🔒 Privacy & Architecture

DevKit is designed around a frontend-only architecture.

- No mandatory backend infrastructure.
- No account registration.
- No cloud database requirement.
- No API keys required.
- No mandatory external API dependencies.
- Browser-based data processing.
- Local preference storage.

User inputs should be processed locally within the browser rather than transmitted to external servers.

**Security note:** JWT decoding does not verify token signatures or establish token authenticity.

## 🚀 Getting Started

You can run DevKit locally on your computer.

### Prerequisites

- Node.js
- npm

### Installation

Clone the repository:

```bash
git clone https://github.com/hussainkapadia57-png/devkit-developer-utility-studio.git
```

Navigate into the project:

```bash
cd devkit-developer-utility-studio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local development URL displayed in your terminal.

### Production Build

Generate an optimized production build:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```

## 📦 Standalone Distribution

DevKit is designed to support independent distribution without requiring public hosting.

The production build can be packaged into a ZIP archive.

Users can:

1. Download the ZIP package.
2. Extract the files.
3. Run the application using a local static server.
4. Access the application through their browser.

No public hosting account is required.
